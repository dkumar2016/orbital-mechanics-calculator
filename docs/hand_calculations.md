# Hand Calculations: Circular Orbits - [400 km, 20,200 Km, 35,786 Km]


Constants: mu = 398,600.4418 km^3/s^2, R_earth = 6,378.137 km
Formulas: v = sqrt(mu/r), T = 2*pi*sqrt(r^3/mu)

```
r = 6,378.137 + 400 = 6,778.137 km
μ/r = 58.806 km²/s², so v = 7.669 km/s
r³ = 3.114 × 10¹¹ km³, r³/μ = 781,256 s², √ = 883.9 s, so T = 2π × 883.9 = 5,553.6 s = 92.56 min
```

## Observations

- Higher orbits are slower but longer, because speed falls as 1/√r and period grows as r^(3/2).”
- 400 km matches the ISS orbital period of about 92 mins
